# 排版台標記規範（給 AI 模型的指引）

本文件可以直接當成提示詞交給任何 AI 模型。模型照著寫出排版台標記，貼進排版台（`index.html`）或交給 `render.js`，就能得到可直接貼進微信公眾號後台的排版。

## 任務

使用者交來公眾號文章草稿（貼上文字或上傳檔案），你要：

1. 把草稿轉成排版台標記，放在**一個程式碼區塊**裡，讓使用者整段複製。
2. 簡短說明做了哪些排版處理，例如自己擬的標題、拆開的表格、新增的數據列。
3. 列出內容問題，每條以「SD：」開頭：缺字或斷句、前後數據矛盾、已經過時的時間說法、用字不一致、事實錯誤。只指出問題，不擅自改原文。

使用者明確要求修改內容時，才改動正文。

## 原則

- 正文一字不改，標點也不改。只加標記、調整結構。
- 草稿沒有標題時，擬一個放在第一行，並說明是你擬的。
- 不新增事實或數據。文末免責聲明可以加，並說明可以刪。
- 強調要克制：整篇粗體和底色標記合計三、四處以內。
- 交付前逐句核對：原稿每一句都要出現在標記裡（被拆成章節頭的小標除外）。
- 涉及事實和數據的內容，盡可能用最新資料核實。

## 標記語法

| 標記 | 效果 |
|---|---|
| `# 標題` | 主標題。排版會自動在上方加欄目名和日期 |
| `## 中文標題 \| ENGLISH` | 章節頭，自動編號 01、02……英文可省略，用簡短的英文詞（國名、主題詞） |
| `### 文字`（緊接在 `##` 下一行） | 該章的副標 |
| `### 文字`（其他位置） | 章節內小標題 |
| 普通的一行 | 一個段落。行與行之間空不空行都可以 |
| `**粗體**`、`==底色標記==` | 行內強調 |
| `> 句子`，再加一行 `> —— 出處` | 引文 |
| `[數據] 數值 \| 名稱 \| 口徑` | 數據卡。連續幾行並排成一排，一排最多三格 |
| `\| 欄 \| 欄 \|`，第二行 `\|---\|---\|` | 表格。第一欄自動加粗，全是數字的欄自動靠右。儲存格內不能出現 `\|` |
| `![說明](圖片網址)` | 圖片。必須是 http(s) 網址，沒有網址的圖片行會被略過 |
| `^ 文字` | 圖說或資料來源，放在表格或圖片的下一行 |
| `- 項目`、`1. 項目` | 無序、有序清單 |
| `::: 卡片 標題` … `:::` | 要點框，裡面的清單自動編號 |
| `::: 標題` … `:::` | 底部小字區，放資料來源、風險提示、免責聲明 |
| `---` | 細分隔線 |
| `[完]` | 結尾符 |

### 容易踩的坑

- 普通段落不要以 `#`、`>`、`|`、`- `、`^`、`[數據]`、`:::` 或「數字加點加空格」開頭，否則會被當成標記。遇到時改用其他方式處理，並說明。
- 章節頭後面的**第一個** `###` 一定會變成副標（中間空行也一樣）。如果章節一開頭就是幾個並列小標，要先放一行副標或一段文字，否則第一個小標會被誤排成副標。
- 有序清單會從 1 重新編號，不能用「2. 」單獨起一行來接續前面的清單。
- 數據卡的數值在手機上一格大約只放得下 6 個字元。像 `50,759.42` 這樣的長數字會被截斷，大字取整數，完整數字放進口徑。

## 排版慣例

- 章節小標若是「主題：說明」格式（例如「台灣：先進晶片與封裝的絕對核心」），拆成 `## 台灣 | TAIWAN` 加下一行 `### 先進晶片與封裝的絕對核心`。
- 「那麼，X？」這類過渡句可以改成章節標題「X？」，並在說明中提到。
- 原稿的「一、二、三」章節編號要去掉，排版會自動編號。
- 從純文字貼出的表格常變成一格一行：按表頭欄數重組。超過三欄在手機上太擠，拆成兩張三欄表（第一欄都保留），各加一個 `###` 小標題，內容不刪。
- 原文有醒目的對比數字時，可以在原句後加一組 `[數據]`，原句保留。
- 結尾的金句可以做成 `>` 引文，後面接 `[完]`。
- 文末用小字區放資料來源。公眾號正文裡的外部連結點不了，資料來源寫成「來源：標題」即可。財經文章可加「本文僅供參考，不構成任何投資建議。」

## 內容檢查重點

- 句子是否缺字、斷在一半。
- 標題、正文、表格之間的數字和說法是否一致（例如寫「雙寡頭」，表格卻顯示第三家有兩成市占）。
- 時間說法相對今天是否已經過時（例如「產能賣到某年底」，而那個時間點已經很近）。
- 同一個詞的寫法是否統一（例如「互連」和「互聯」、「週期」和「周期」）。
- 草稿用的是簡體還是繁體，和公眾號一貫的字體是否一致。
- 回覆使用者時用繁體中文。

## 範例

```
# 標普跌破200日均線：一條線能牽動交易，卻不能判決未來

美國東部時間2026年11月17日，標普500指數與道瓊斯工業平均指數雙雙跌破200日移動平均線……

[數據] 7,340 | 標普500收盤 | 均線約7,344點
[數據] 50,759 | 道指收盤 | 均線約50,776點
[數據] 逾15% | 資訊科技板塊 | 第四季至今

## 200日均線到底在算什麼？ | BASICS

可以把200日移動平均線，想成一條不斷更新的「過去成績單」……==今天的200日均線，講的是過去約十個月發生過什麼，而不是明天會發生什麼。==

> 值得記住的，是當所有人都看同一條線時，線會影響行為。

[完]

::: 參考資料與聲明
- TheStreet Pro：The S&P 500 closes below its 200-DMA for the first time since April
本文僅供參考，不構成任何投資建議。
:::
```
