使用说明

一、怎么复制到公众号

  1. 用 Chrome / Edge / Safari 打开任意一个模板 HTML（双击文件即可）。
  2. 点页面顶部的「一键复制全文」按钮（或手动 Ctrl/Cmd+A 全选 → Ctrl/Cmd+C）。注意：要复制“渲染后的页面”，不是复制 HTML 源码。
  3. 打开 mp.weixin.qq.com → 新建图文 → 在正文区 Ctrl/Cmd+V 粘贴。
  4. 样式和手绘图片会一起带过去，图片会被公众号自动转存到素材库。粘贴后滚动检查一遍，确认图片都显示。

二、怎么替换内容

  1. 所有占位文字都写成 【在这里粘贴……】，直接在公众号编辑器里选中替换即可，样式会保留（建议用「粘贴为纯文本」Ctrl+Shift+V 粘贴你的正文，再选中局部去设置强调）。
  2. 不需要的模块，选中整块（点一下边框再按 Delete）删掉；想复用某块，复制该块再粘贴到别处。
  3. 单个组件可以去 components.html，点每个组件下面的「复制此组件」，像搭积木一样拼。
  4. 强调词：把 components.html 里“强调样式合集”复制过来，再改字。

三、关于图片

  1. 装饰图（横幅、分割线、图标、胶带、花草）都在 assets/ 里，粘贴时公众号会自动上传，无需手动处理。
  2. 二维码：模板里是一个手绘边框的占位图，粘贴后点击该图 → 更换图片 → 上传你自己的公众号二维码即可（建议 600×600 以上）。
  3. 如果粘贴后图片显示为裂图：说明浏览器没有把图片一起复制。改用方法：在编辑器里逐张点图片 → 替换 → 从 assets/ 选择对应文件。
  4. 想换颜色或改涂鸦：运行 tools/make_assets.py 重新生成，再运行 tools/build.py 重新生成模板。

四、小提醒

  1. 公众号会清除 <style>、class、脚本、外部字体，所以本套模板全部使用行内样式；标题用了楷体优先字体栈，iOS / 电脑端显示楷体，部分安卓机会回退成默认黑体。
  2. 荧光笔效果用的是渐变背景，个别旧版客户端不显示时，文字仍然是加粗的，不影响阅读。
  3. 公众号正文外链不可点击，资料来源请写文字来源。
  4. 每篇结尾都带有「不构成投资建议」的免责声明，请保留。
